# 한글 입력 스파이크

Bubble Tea v2 + `bubbles/textarea` 로 한국어를 칠 때 깨지지 않는지 확인한다.
이 스파이크가 통과해야 S1 재생 뷰를 이 입력창 위에 쌓는다.

## 실행

```
cd spikes/hangul-input
go run .
```

## 확인할 것 4가지

| # | 확인 | 통과 기준 |
|---|---|---|
| 1 | 한글이 깨지지 않는가 | `새벽 코딩용, 가사 없는 걸로` 가 그대로 보인다 |
| 2 | 커서가 글자를 따라가는가 | 타이핑 중 커서가 마지막 글자 바로 뒤에 있다 |
| 3 | 지우기가 정확한가 | Backspace 한 번에 한 글자씩 지워진다 (자모 단위로 깨지지 않음) |
| 4 | 폭 계산이 맞는가 | 화면의 `\|새벽 코딩용...\|` 과 `\|-----\|` 두 줄의 **오른쪽 끝이 정확히 일치**한다 |

4번이 핵심이다. 한글은 표시폭 2, 영문은 1이라 이 계산이 틀리면
모든 화면의 테두리와 정렬이 어긋난다.

## 조작

- `Enter` — 전송 (아래 목록에 쌓인다)
- `Esc` / `Ctrl+C` — 종료

## 결과

- ✅ 통과 → Bubble Tea 로 확정, S1 재생 뷰 착수
- ❌ 실패 → Ink 로 선회 (화면 설계는 docs/ 에 있으므로 교체 비용은 거의 없음)
