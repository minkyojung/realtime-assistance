## 3. 반드시 지킬 것 셋

이걸 어기면 이 물건은 그냥 tmux 가 됩니다.

### ① 자기 키 바인딩을 만들지 않는다

하고 싶은 것은 `Commands()` 로 등록합니다. 호스트가 전부 모아 `/` 팔레트
하나로 보여줍니다.

```go
func (m Model) Commands() []app.Command {
    return []app.Command{
        {Name: "/dnd", Help: "turn on do not disturb", Run: ...},
    }
}
```

**처음 여는 앱에서도 `/` 를 누르면 뭘 할 수 있는지 보이고, `ctrl+f` 로 찾고,
`tab` 으로 넘길 수 있어야 합니다.**

### ② 결과는 `app.Say()` 로 로그에 남긴다

```go
return app.Say(m.Name(), "알림을 껐습니다")
app.SayErr(m.Name(), err)   // 실패도 대화의 일부다
```

자기 화면에만 쓰면 **다른 앱을 보고 있는 사용자에게는 아무 일도 안 일어난
것처럼 보입니다.** `"조용한 거 틀고 알림 꺼줘"` 는 두 앱에 동시에 가고,
그 결과가 만나는 곳은 로그뿐입니다.

### ③ `Init(send)` 로 밀어 넣는다

**이 앱의 존재 이유입니다.**

음악은 우리가 1초마다 물어봅니다(폴링). 채팅은 저쪽에서 옵니다.
`send` 는 이벤트 루프 **밖에서** 메시지를 넣는 통로입니다.

```go
func (m Model) Init(send func(tea.Msg)) tea.Cmd {
    go func() {
        for ev := range socket.Events() {
            send(incomingMsg{ev})
        }
    }()
    return nil
}
```

하네스가 옳게 그어졌는지도 여기서 증명됩니다 —
**음악만 보고 만들었으면 이 통로가 없었을 겁니다.**

## 4. 단계와 증거

| | 하는 일 | 끝났다는 증거 |
|---|---|---|
| **1** | 관문 | ✅ 이미 됨. 토큰 없이 켜면 `LOGIN` 배지 |
| — | **사용자가 Slack App 생성 + 토큰 발급** | `.env` 에 값이 들어감 |
| **2** | 읽기 — 대화 목록 · 안 읽음 | 상태줄에 진짜 `chat 3` |
| **3** | **밀어넣기 — Socket Mode** | **음악 화면을 보는 중에 숫자가 저절로 오른다** |
| **4** | 쓰기 — 메시지 · 방해금지 | `@chat 팀한테 늦는다고 보내줘` |
| **5** | 합류 | `"조용한 거 틀고 알림 꺼줘"` 한 문장에 둘 다 |

**3단계가 진짜입니다.** 다른 앱을 보고 있는데 배지가 오르면 하네스가
제대로 된 겁니다.

---

## 5. 사용자가 해야 하는 것

제가 대신 못 합니다. 1단계 화면이 이걸 안내합니다.

1. <https://api.slack.com/apps> 에서 앱 생성
2. **Socket Mode** 켜기 → app-level token (`xapp-...`)
3. **User Token Scopes** 추가 — 최소한:
   `channels:read` `groups:read` `im:read` `im:history` `chat:write` `dnd:write`
4. 워크스페이스에 설치 → user token (`xoxp-...`)
5. 저장소 루트 `.env` 에 추가

```
SLACK_APP_TOKEN=xapp-...
SLACK_USER_TOKEN=xoxp-...
```

뼈대는 `SLACK_USER_TOKEN` 만 읽고 있습니다. 3단계에서 `SLACK_APP_TOKEN` 이
필요해집니다.
