# Apple Music CLI — AI 레이어

> PDF 6장 "고려사항"의 재료 + API 설계의 전제.
> 작성일: 2026-09-08 (화, D1)

---

## 원칙

```
AI는 "번역"과 "설명"만 한다.  "실행"과 "집계"는 코드가 한다.
```

이 경계를 지키면 결과가 재현 가능하고, 비용이 예측 가능하며,
API 명세가 확률적 동작에 오염되지 않는다.

---

## 1. AI가 필요한 이유 — 없는 데이터를 만들어야 한다

| 필요한 것 | Apple이 주는가 |
|---|---|
| 제목 · 아티스트 · 장르 · 연도 · BPM | ✅ |
| 재생 횟수 · 마지막 재생일 · 스킵 횟수 | ✅ (Music.app) |
| **에너지 · 무드 · 상황(집중/운동/새벽) · 가사 유무 성향** | ❌ **제공하지 않음** |

Spotify와 달리 Apple Music은 오디오 특성(audio features)을 노출하지 않는다.
**"새벽 코딩용"을 필드로 표현할 방법이 원천적으로 없다.**
그 빈칸을 메우는 것이 AI 레이어의 존재 이유다.

## 2. 레이어 6개

| 레이어 | 하는 일 | 입력 | 출력 형식 | 시점 |
|---|---|---|---|---|
| **L1 색인** | 곡 → 무드·상황 태그 | 메타데이터 (제목·아티스트·앨범·장르·연도·BPM) | 구조화 출력 (JSON Schema) | **배치 1회 + 캐시** |
| **L2 질의 해석** | 자연어 → 조회 조건 | 사용자 입력 + 태그 어휘 | 구조화 출력 → SQL 조건 | 요청 시 |
| **L3 선곡** | 후보 → 순서 있는 큐 | 후보 50곡 + 반응 이력 + 취향 규칙 | 곡 ID 배열 | 요청 시 |
| **L4 근거** | 곡 → 한 줄 이유 | 곡 + 재생 이력 + 선정 조건 | 문장 1개 | 요청 시 (병렬) |
| **L5 반응 해석** | 반응 누적 → 취향 규칙 | 최근 반응 N건 | 구조화 출력 | 주기 배치 |
| **L6 재편성** | 지시 → 큐 수정 | 현재 큐 + 지시 + 대화 이력 | 곡 ID 배열 | 요청 시 |

### L1이 전체를 지탱한다

L1을 미리 돌려 캐시해 두어야 L2·L3가 빨라진다.
**실시간 경로에 태깅을 두면 큐 생성이 수십 초가 되어 제품이 성립하지 않는다.**

| 항목 | 값 |
|---|---|
| 대상 | 라이브러리 전곡 (약 3,000곡) |
| 실행 | 최초 1회 + `/sync` 시 신규 곡만 |
| 출력 | `Track.mood_tags`, `Track.context_tags`, `Track.energy` |
| 무효화 | 곡 메타데이터 변경 시에만 |

## 3. AI를 쓰지 않는 곳

| 동작 | 처리 |
|---|---|
| 재생 · 정지 · 다음 곡 | AppleScript |
| 재생률 · 죽은 곡 수 집계 | SQL |
| 조건 필터링 · 정렬 실행 | SQL |
| Shazam 곡 인식 | ShazamKit |
| 인식 결과 ↔ 라이브러리 대조 | `appleMusicID` / ISRC **정확 일치** |
| 슬래시 명령 전부 | 코드 |

> **대조를 AI에게 시키지 않는다.** "이 곡이 내 라이브러리에 있는가"는
> 판정이지 해석이 아니다. 확률적으로 답하면 F11의 주장 자체가 무너진다.

---

## 4. 비용 구조

| 레이어 | 빈도 | 규모 |
|---|---|---|
| L1 | 1회 (+증분) | 3,000곡 × 짧은 태깅 |
| L2 · L3 · L6 | 큐 요청당 1~2회 | 후보 목록이 컨텍스트 |
| L4 | 큐당 곡 수만큼, 병렬 | 문장 1개씩 |
| L5 | 하루 1회 | 반응 N건 |

**실시간 비용은 L2~L4에만 발생하고, 상태줄에 누적 비용으로 표시한다.**
(agentic CLI의 관례이자, 사용자가 AI 사용량을 통제할 수 있게 하는 장치)

---

## 5. 실패 처리

| 레이어 | 실패 시 | 화면 |
|---|---|---|
| L1 | 태그 없는 곡으로 남김. 조회에서 제외되지 않고 낮은 우선순위 | — |
| L2 | 조건 추출 실패 → 원문을 제목·아티스트 검색으로 대체 (**폴백**) | E4 |
| L3 | 실패 → 규칙 기반 정렬(최근 미재생 우선)로 대체 | E4 |
| L4 | 실패 → 근거 없이 곡만 표시 (재생은 막지 않음) | — |
| L5 | 실패 → 기존 규칙 유지 | — |
| L6 | 실패 → 현재 큐 유지 + 재시도 안내 | E4, E8 |

> **어떤 AI 레이어가 죽어도 음악은 계속 재생된다.**
> L1~L6은 전부 품질 향상 경로이지, 재생 경로가 아니다.
