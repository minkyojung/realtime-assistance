# Relay — 액터별 기능 요구사항

> 산출물 ②. PDF 2장 "시스템 액터 정의" 재료.
> 모든 기능은 화면에 배치되고, 화면의 모든 요소는 기능에서 나온다.

---

## 제품 구조 — 미팅 전·중·후

```
Before        참석자와 목표를 정하고, 준비된 답변으로 무장한다
   ↓
In Progress   상대 질문에 즉답하고, 내 목표가 다뤄졌는지 체크한다
   ↓
After         요약·할 일·개선점을 남긴다
   ↓
              (할 일을 처리하면 다음 미팅의 Before가 된다)
```

**대화를 양방향으로 본다.** 이것이 설계의 중심이다.

| 방향 | 무엇 | 시스템이 하는 일 |
|---|---|---|
| 상대 → 나 | `question` | 답을 제공한다 |
| 나 → 상대 | `session_goal` | 물었는지 확인한다 |

---

## 액터 3명

| 액터 | 누구인가 | 주 화면 | 단계 |
|---|---|---|---|
| **발화자** | 고객을 만나는 세일즈·PM | 실시간 어시스트 패널 | Before + In Progress |
| **정리자** | 미팅을 마친 담당자 (보통 발화자 본인) | 회의 결과 | After |
| **지식 관리자** | 제품팀·운영 담당 | 준비된 답변 관리 | 상시 |

> 발화자와 정리자는 대개 같은 사람이다. 하는 일과 시점이 달라 액터를 나눈다.

## A. 발화자 — 실시간 어시스트 패널

### A-1. Before (미팅 시작 전)

| # | 기능 | 화면 구역 | 비고 |
|---|---|---|---|
| A1 | 세션을 시작한다 | 시작 폼 | 상대 조직, 도메인, 컨텍스트 |
| A2 | **참석자 정보를 입력한다** | 시작 폼 | 이름, 소속, 직책, 사전 메모 |
| A3 | **미팅 목표를 적는다** | 시작 폼 | "예산 규모 확인" 등. 여러 개 |
| A4 | 준비된 답변을 미리 훑는다 | (선택) | 관련 답변 미리보기 |

### A-2. In Progress (미팅 중)

| # | 기능 | 화면 구역 | 비고 |
|---|---|---|---|
| A5 | 오디오 캡처를 켜고 끈다 | 상단 pill | 마이크/시스템 오디오 |
| A6 | 대화 전사를 본다 | 대화 흐름 | 화자 구분 |
| A7 | **판정 카드를 본다** | 하단 고정 | **핵심 기능** |
| A8 | 할 말 문구를 본다 | 하단 고정 | `suggested_script` |
| A9 | 출처를 확인한다 | 하단 고정 | GitHub 원문 링크 |
| A10 | **목표 체크 상태를 본다** | 목표 트레이 | 다뤄진 것/남은 것 |
| A11 | **목표를 수동 체크한다** | 목표 트레이 | 자동 감지가 놓쳤을 때 |
| A12 | 컨텍스트를 수정한다 | 상단 pill | 대화 중 NDA 체결 등 |
| A13 | 세션을 종료한다 | 상단 pill | 요약 생성으로 이어짐 |

### A7 판정 3종

| 표시 | `response_mode` | 언제 | 사용자가 할 일 |
|---|---|---|---|
| 🟢 초록 | `direct` | 준비된 답변 있음, 조건 충족 | 문구 그대로 말한다 |
| 🟡 노랑 | `conditional` | 답변 있으나 조건 미충족 | 조건부 문구를 말한다 |
| 🔴 빨강 | `escalate` | 답변 없음 / `intent=when` | 확인 후 회신을 말한다 |

## B. 정리자 — 회의 결과

| # | 기능 | 화면 구역 | 비고 |
|---|---|---|---|
| B1 | **회의 요약을 본다** | 요약 | 세션 종료 시 자동 생성 |
| B2 | **목표 달성률을 본다** | 요약 | 물으려던 것 중 몇 개를 물었나 |
| B3 | **개선점을 본다** | 요약 | 다음에 다르게 할 것 |
| B4 | **할 일 목록을 본다** | 할 일 | 세 종류가 한 목록 |
| B5 | 할 일을 추가한다 | 할 일 | 자동 생성에서 빠진 것 |
| B6 | 할 일을 완료 처리한다 | 할 일 | |
| B7 | 답변이 필요한 항목에서 답변을 작성한다 | 할 일 → 답변 폼 | **다음 미팅의 무기가 됨** |
| B8 | 전사 기록을 다시 본다 | 전사 | 근거 확인 |
| B9 | 요약을 재생성한다 | 요약 | |

### B4 할 일 3종

| `type` | 의미 | 어디서 생기나 |
|---|---|---|
| `follow_up` | 자료 발송, 재미팅 등 | 요약 생성 시 / 못 다룬 목표에서 이월 |
| **`answer_needed`** | **답하지 못한 질문** | 🔴 판정이 난 질문에서 |
| `improvement` | 다음에 다르게 할 것 | 요약 생성 시 |

> **셋을 한 목록에 두는 이유:** 사용자 입장에서 "회의 끝나고 처리할 것"이라는 점이 같다.
> 구분해야 할 이유가 없다.

### B7이 루프를 닫는다

```
🔴 답 못 함 → answer_needed 할 일 → 답변 작성 → 다음 미팅에서 🟢
```

## 기능 ↔ 화면 매핑 검증

| 화면 | 담당 기능 | 개수 |
|---|---|---|
| 실시간 어시스트 패널 | A1~A13 | 13 |

| 준비된 답변 관리 | C1~C11 | 11 |

**모든 기능이 화면에 배치됐고, 배치되지 않은 기능은 없다.**

## 단계 간 연결

```
Before
  A3 목표 입력 ─────────────────┐
                              │
In Progress                    ↓
  A7 판정 🔴 ──┐          A10 목표 체크
              │               │
After         ↓               ↓ (못 다룬 것)
  B4 할 일  ◀─┴───────────────┘
       │
       ├─ answer_needed → B7 답변 작성 ─┐
       └─ follow_up / improvement       │
                                       ↓
                            다음 미팅의 Before
```

**After가 다음 Before로 이어지면서 순환이 완성된다.**

## 지표 — 두 축

| 지표 | 계산 | 무엇을 말하나 |
|---|---|---|
| **즉답률** | `escalate 아닌 질문 / 전체 질문` | 상대 질문에 얼마나 답했나 |
| **목표 달성률** | `covered 목표 / 전체 목표` | 내가 물으려던 걸 얼마나 물었나 |
| 미처리 할 일 | `action_item where status='open'` | 밀린 일 |

**대화가 양방향이므로 지표도 두 개다.**
