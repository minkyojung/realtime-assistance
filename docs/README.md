## 제품 구조

```
Before        참석자·목표를 정하고 준비된 답변으로 무장
In Progress   상대 질문에 즉답 + 내 목표가 다뤄졌는지 체크
After         요약·할 일·개선점 → 다음 미팅의 Before
```

대화를 **양방향**으로 본다.

| 방향 | 데이터 | 지표 |
|---|---|---|
| 상대 → 나 | `question` | 즉답률 |
| 나 → 상대 | `session_goal` | 목표 달성률 |
