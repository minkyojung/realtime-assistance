발표 슬라이드용 그림.

  loop.svg   원본 — Keynote·PowerPoint 에 그대로 끌어다 놓을 수 있다 (벡터라 안 깨진다)
  loop.png   1920×1080 — 붙여넣기만 하면 되는 쪽

고칠 것이 있으면 svg 를 고치고 다시 뽑는다:

  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless \
    --window-size=1920,1080 --screenshot=loop.png file://$PWD/_wrap.html

색은 TUI 팔레트와 같다 — 배경 #17171b, 강조 #ff5a75. 캡처와 나란히 놓아도 한 벌로 보인다.
