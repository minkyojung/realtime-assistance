# 화면 표시 필드 전수

> **DB(DBML)와 API(YML)의 재료다.** 화면에 보이는 값을 먼저 전부 적고,
> 여기서 컬럼과 응답 필드를 뽑는다. 반대 순서로 하면 "UI 데이터가 ERD에
> 없음"(최대 감점)이 확정된다.
>
> 실제 코드(`tui/internal/`)에서 뽑았다. Shazam 은 범위에서 제외.
> 작성일: 2026-09-09

## 출처 표기

| 표기 | 뜻 | DB 컬럼이 되는가 |
|---|---|---|
| **저장** | 우리가 갖고 있어야 하는 값 | **된다** |
| 실시간 | Music.app · 외부가 그때그때 주는 값 | 안 된다 |
| 계산 | 다른 값으로 만드는 값 | 안 된다 |
| 고정 | 코드에 박힌 문구 | 안 된다 |

## S2. 지금 재생 — 큰 형태

`musicapp/artwork.go` · `lyrics.go`

| # | 보이는 값 | 출처 | 근거 |
|---|---|---|---|
| 1 | 앨범 커버 이미지 | 실시간 | Music.app `raw data of artwork` |
| 2 | 재생 / 정지 아이콘 | 실시간 | |

| 4 | 아티스트명 | **저장** | `artist.name` |

| 6 | 진행바 | 계산 | 위치 ÷ 길이 |
| 7 | 재생 위치 `mm:ss` | 실시간 | |
| 8 | 곡 길이 `mm:ss` | **저장** | `track.duration_ms` |
| 9 | 가사 (현재 줄 하이라이트) | 실시간 | LRCLIB |
| 10 | 장르 · 발매연도 | **저장** | `track.genre` · `track.year` |
| 11 | 라이브러리 추가일 + "3년 전" | **저장** + 계산 | `track.added_at` |
| 12 | 마지막 재생일 + 경과 | **저장** + 계산 | `track.last_played_at` |

> 9~14 는 같은 자리를 나눠 쓴다. 가사가 있으면 가사, 없으면 곡 이력.

## S6. 목록 패널 — 구역별 추가 표시

| 구역 | 추가로 보이는 값 | 출처 | 근거 |
|---|---|---|---|
| Recently Added | `added_at` 내림차순 | **저장** | `track.added_at` |
| Queue | 순번 | **저장** | `queue_item.position` |
| Queue | **선정 근거 한 줄** (대화 띠에서) | **저장** | `queue_item.reason` |
| Queue | 큐 제목 (상태줄) | **저장** | `queue.title` |
| Never played | 한 번도 안 튼 곡만 | 계산 | `last_played_at IS NULL` |
| Apple Music | 보유 표시 `✓` / `+` / `⋯` | 계산 | 라이브러리 대조 |
| Apple Music | 검색 결과 제목 · 아티스트 | 실시간 | Apple Music API |
| 플레이리스트 | 플레이리스트명 · 곡 수 | **저장** | `playlist.name` |

## S7. 로그 띠

`host/log.go` · `musicapp/detail.go`

| # | 보이는 값 | 출처 | 근거 |
|---|---|---|---|
| 1 | 말한 주체 (나 / 앱 이름) | **저장** | `message.role` |
| 2 | 문장 | **저장** | `message.text` |
| 3 | 실패 여부 | **저장** | `message.is_error` |
| 4 | 대기 스피너 | 실시간 | 답이 앉을 자리에 그대로 앉는다 |
| 5 | 후보 수 → 고른 곡 수 · 총 길이 | **저장** | `turn.candidate_count` |
| 6 | **곡별 선정 근거** | **저장** | `queue_item.reason` |
| 7 | 모델명 · 소요 초 · 토큰 ↑↓ · $비용 | **저장** | `turn.model` · `elapsed_ms` · 토큰 · `cost_usd` |

> 마지막 한 판을 통째로 보여준다 — 내 말, 답, 곡별 근거, 비용까지. 최대 10줄이고,
> 남는 자리만큼만 근거가 붙는다. `ctrl+j` 로 접으면 마지막 한 줄만 남는다.

## 여기서 나온 "저장할 것" — 다음 단계(ERD)의 입력

| 묶음 | 값 |
|---|---|
| 곡 | 제목 · 길이 · 장르 · 연도 · 재생 횟수 · 추가일 · 마지막 재생일 · Music.app 키 |
| 아티스트 | 이름 |
| 앨범 | 제목 · 소속 아티스트 |
| 플레이리스트 | 이름 · 담긴 곡 · 순서 |
| 큐 | 제목 · 순번 · **선정 근거** · 넣은 주체 |
| 대화 | 주체 · 문장 · 실패 여부 · 시각 |
| AI 요청 | 모델명 · 후보 수 · 소요 시간 · 토큰 ↑↓ · 비용 |
| 설정 | Apple Music 팀 ID · 사용자 토큰 · AI 키 보유 |
| 재생 사건 | 언제 · 어느 곡 · 몇 ms 듣고 · 왜 끝났나 · 섞기였나 |

✅ 화면에 보이는 모든 값이 위 셋 중 하나로 분류됐다.
