## 1. 물음표 — 한국어 어미 문제를 STT가 대신 풀어준다

`gpt-4o-transcribe` / `gpt-4o-mini-transcribe` 결과 (동일)

| 문장 | 유형 | 전사 결과 | 부호 |
|---|---|---|---|
| 온프레미스 배포 되나요? | 질문 | 온프레미스 배포 되나요**?** | ✅ |
| SAML SSO 연동은 지원하시나요? | 질문 | …지원하시나요**?** | ✅ |
| SOC 2 인증도 받으셨나요? | 질문 | …받으셨나요**?** | ✅ |
| **그건 확인해봐야 할 것 같은데요** | **비질문** | …같은데요**.** | ✅ |
| **언제 한번 자리 마련하죠** | **비질문** | …마련하죠**.** | ✅ |
| 그러니까 이게 음 되는 건가요? | 질문 | …되는 건가요**?** | ✅ |
| Edge Functions … 언제 지원되나요? | 질문 | …언제 지원되나요**?** | ✅ |

### 의미

`KoSEnd` 연구는 **한국어 종결어미가 모국어 화자조차 일관되게 분류하지 못할 만큼 모호**하다고
보고했고, 이것이 우리 정규식 계획의 최대 위험이었다.

**그런데 STT가 이미 그 판단을 끝내서 문장부호로 내려준다.**

특히 우리가 설계한 두 함정을 모두 통과했다.

- `"~것 같은데요"` — 종결어미가 애매하나 **마침표**
- `"언제 한번 자리 마련하죠"` — `언제`가 있고 `~죠`로 끝나지만 **마침표**

정규식이라면 둘 다 오탐했을 케이스다.
**질문 감지 1차 신호를 `?` 하나로 가져갈 수 있다 → 예산 0ms, 한국어 모호성 우회.**

## 2. 영문 약어 — 프롬프트 없이는 전멸

우리 도메인의 검색 키는 대부분 영문 고유명사이고,
**하이브리드 검색에서 BM25 비중을 높게 잡기로 한 전제**가 여기에 걸려 있다.

| 원문 | prompt 없음 | **prompt 있음** |
|---|---|---|
| SAML SSO | 샘류 SSO / 생리수혜수 / 팀리 SSO | ✅ **SAML SSO** |
| SOC 2 | 사기 / 세기 | ✅ **SOC 2** |
| Edge Functions | 매직 펑션즈 | ⚠️ 에지 펑션즈 (음차, 부분 개선) |

### 해법 — 세션 시작 시 어휘 사전을 STT에 주입한다

```
prompt = "SAML, SSO, SOC 2, HIPAA, Edge Functions, Supabase, 셀프호스팅, 온프레미스"
```

이것만으로 `SAML SSO`, `SOC 2`가 원형으로 복구된다.

**설계적 함의: 지식 소스가 인식 정확도를 올린다.**
GitHub 레포에서 제품명·기능명·라벨을 추출해 어휘 사전을 자동 생성하고,
세션 시작 시 STT `prompt`로 주입한다. 지식 인입 파이프라인의 부산물로 공짜로 얻는다.

### 남는 문제

`Edge Functions` → `에지 펑션즈` 는 여전히 음차된다.
→ **전사 후처리 정규화 사전**이 추가로 필요하다. (`에지 펑션즈` → `Edge Functions`)
→ 사전 역시 GitHub 어휘에서 자동 생성 가능.

## 3. `gpt-live-transcribe`

`POST /v1/audio/transcriptions` 에서 `Invalid URL` 반환.
**Realtime WebSocket 전용 모델**로 보인다. 2단계(실시간 스트리밍)에서 확인한다.

배치 전사는 `gpt-4o-transcribe` 계열로 검증했고, 물음표·프롬프트 동작은 동일 계열이므로
Realtime에서도 유지될 가능성이 높으나 **확인 전까지 가정하지 않는다.**

---

## 4. 이 테스트의 한계

- **TTS 음성이라 실제 발화가 아니다.** 말끝 흐림, 잡음, 겹침이 없다.
- 특히 **영문 약어의 TTS 발음 자체가 부정확**했을 수 있다 → 약어 결과는 과대 비관일 가능성
- 턴 종료 감지 지연은 측정하지 못했다 (배치 전사이므로)

**→ 2단계: 실제 녹음 + Realtime WebSocket 스트리밍으로 재검증 필요.**

## 5. 설계에 반영할 것

| 항목 | 변경 |

| 질문 감지 1차 | **`?` 부호를 주 신호로.** 어미 정규식은 보조 |

| 전사 후처리 | **음차 정규화 사전** 추가 (`에지 펑션즈` → `Edge Functions`) |
| 예산표 | 턴 감지 300ms는 여전히 미검증 — 2단계에서 실측 |
