# 화면 표시 필드 전수 열거

> ERD의 입력. **화면에 보이는 모든 값을 먼저 적고, 그것에서 컬럼을 도출한다.**
> 반대 순서로 하면 "UI 데이터가 ERD에 없음"(최대 감점 사유)이 사실상 확정된다.
>
> 작성일: 2026-09-09 (수, D2)

---

## S1. 재생 뷰

| # | 표시되는 값 | 출처 |
|---|---|---|
| 1 | 세션 제목 | `listening_session.title` |
| 2 | 최초 요청 문구 | `listening_session.prompt` |
| 3 | 재생 상태 (재생중/정지) | **런타임** (Music.app 조회, 저장 안 함) |
| 4 | 현재 곡 제목 | `track.title` |
| 5 | 아티스트명 | `artist.name` |
| 6 | 앨범명 | `album.title` |
| 7 | 장르 · 발매연도 | `track.genre` · `track.year` |
| 8 | 앨범 아트 | `album.artwork_url` |
| 9 | **선정 근거 한 줄** | `queue_item.reason` |
| 10 | 재생 위치 | **런타임** |
| 11 | 곡 길이 | `track.duration_ms` |
| 12 | 큐 순번 | `queue_item.position` |
| 13 | 큐 항목 상태 (대기/재생중/스킵됨) | `queue_item.state` |
| 14 | 큐 항목 태그 (최대 2개) | `tag.name` via `track_tag` |
| 15 | 큐 요약 — 곡 수 · 총 길이 | 집계 (`queue_item`, `track.duration_ms`) |
| 16 | 큐 요약 — 죽은 곡 수 | 집계 (`track.last_played_at IS NULL`) |
| 17 | 누적 토큰 · 비용 | `listening_session.prompt_tokens` · `completion_tokens` · `cost_usd` |
| 18 | 요청 진행 상태 (`Thinking...`) | `session_turn.status` |
| 19 | 응답 문장 | `session_turn.assistant_message` |
| 20 | 요청 실패 사유 | `session_turn.error_code` · `error_message` |

## S2. 묘비

| # | 표시되는 값 | 출처 |
|---|---|---|
| 1 | 곡 제목 · 아티스트 · 앨범 | `track.title` · `artist.name` · `album.title` |
| 2 | 라이브러리 추가일 | `track.added_at` |
| 3 | 누적 재생 횟수 | `track.play_count` |
| 4 | **마지막 재생일 / "한 번도 없음"** | `track.last_played_at` (**NULL = 한 번도 없음**) |
| 5 | 경과 기간 | 계산 (`now - last_played_at`, NULL이면 `now - added_at`) |
| 6 | 스킵 횟수 | `track.skip_count` |
| 7 | 무드 · 상황 태그 | `tag.name` via `track_tag` |
| 8 | 제외 표시 여부 | `track.excluded` |
| 9 | 라이브러리 소속 여부 | `track.in_library` — 플레이리스트에만 있는 곡을 구분 |
| 9 | 필터 기준 (never / N개월) | 쿼리 파라미터 |

## S3. 라이브러리 진단

| # | 표시되는 값 | 출처 |
|---|---|---|
| 1 | 총 곡 수 | 집계 (`track`) |
| 2 | **한 번도 재생 안 함 — 곡 수 · 비율** | 집계 (`last_played_at IS NULL`) |
| 3 | 최근 30일 / 1년 재생 곡 수 | 집계 (`last_played_at`) |
| 4 | 가장 오래된 마지막 재생 | 집계 (`MIN(last_played_at)`) |
| 5 | 스트리밍 / 로컬 파일 곡 수 | 집계 (`track.source`) |
| 6 | 태그 미부여 곡 수 | 집계 (`track_tag` 부재) |
| 7 | 마지막 동기화 시각 | `sync_run.finished_at` |
| 8 | 동기화 상태 · 처리 곡 수 | `sync_run.status` · `sync_run.track_count` |

## S4. 취향 규칙

| # | 표시되는 값 | 출처 |
|---|---|---|

| 2 | 규칙 조건 (구조화) | `taste_rule.condition` |
| 3 | 근거가 된 반응 횟수 | `taste_rule.evidence_count` |
| 4 | 활성 여부 | `taste_rule.active` |

## S5. 인식 결과 (Shazam)

| # | 표시되는 값 | 출처 |
|---|---|---|
| 1 | 인식된 제목 · 아티스트 | `recognition.title` · `recognition.artist_name` |
| 2 | 연도 · 장르 · ISRC | `recognition.year` · `genre` · `isrc` |
| 3 | 아트워크 | `recognition.artwork_url` |
| 4 | **라이브러리 보유 여부** | `recognition.matched_track_id` (**NULL = 미보유**) |
| 5 | 보유 시 — 추가일 · 재생 횟수 · 마지막 재생일 | `track.added_at` · `play_count` · `last_played_at` |
| 6 | 인식 시각 | `recognition.recognized_at` |
