# Apple Music CLI — TUI

Bubble Tea v2 기반 터미널 클라이언트.

## 레이아웃 — Apple Music 과 같은 모양

```
┌──────────────────────────────────────────┐
│ ████  Perth                              │  커버 + 곡 정보 + 진행 바
│ ████  ▶ ━━━●──────  1:00 / 4:22          │
│ ████    Everybody's watching her         │  가사 (재생 위치 따라)
│ ████  ▸ Oh, oh, oh                       │
├──────────────────────────────────────────┤
│   Please Wait for Me      Busker Busker  │  목록 — 남는 자리 전부
│   ⋮                                      │
├──────────────────────────────────────────┤
│ › 조용한 거 25분치                        │  대화 — 입력창 바로 위
│ ▸ 최근에 거의 안 들은 걸로 25분 맞췄어요   │
│    1. Babys   담은 지 31일, 0회 재생      │
│ ╭──────────────────────────────────────╮ │
│ │ Ask AI                               │ │  입력창
│ ╰──────────────────────────────────────╯ │
│ Recently Added · 164              $0.02  │  상태줄
└──────────────────────────────────────────┘
```

**고정 줄 수를 두지 않는다.** 목록은 남는 자리를 전부 먹는다 — 창을 키우면
그만큼 더 보인다. 한때 열네 줄 상한이 있었는데 그 아래가 스무 줄씩 비었다.

**빈 공간은 가장자리에 둔다.** 입력창과 상태줄은 언제나 맨 아래다.

**답이 손가락 바로 위에 온다.** 답이 화면 꼭대기에 뜨면 바닥에서 치고
꼭대기에서 읽느라 눈이 왕복한다.

**사이드바가 없다.** 갈 수 있는 곳은 `/` 가 보여준다 — 터미널에서는
가로가 세로보다 귀하다.

## 설정 — 셸이 아니라 앱 안에서

한때 자격 증명을 환경변수로만 받았다. 그것은 서버·컨테이너의 방식이고
데스크톱 CLI 에는 안 맞는다 — 터미널마다 다시 `export` 해야 하고, 셸을 안
거치고 띄우면 아예 못 받고, 껐다 켜면 사라진다.

**전부 앱 안에서 받는다. 셋 다 건너뛸 수 있고, 건너뛰면 그 기능만 꺼진다.**

| 명령 | 켜는 것 | 없으면 |
|---|---|---|
| `/ai <key>` | 말 걸어서 큐 만들기 | 검색·재생만 |
| `/setup <team ID>` | 애플 뮤직 전체 검색 | 내 라이브러리만 |
| `/login` | 라이브러리에 담기 | 재생만 |

첫 화면이 무엇이 꺼져 있는지 말한다.

### 어디에 사는가

| | 어디 | 왜 |
|---|---|---|
| p8 개인키 | `~/.config/amcli/AuthKey_<KEYID>.p8` (0600) | 라이브러리가 경로를 받는다 |
| Key ID · Team ID | `~/.config/amcli/config.json` | **비밀이 아니다** — 개발자 포털에 그냥 보인다 |
| AI 키 · Music User Token | **키체인** | 뽑히면 남의 돈·남의 계정이다 |

`AuthKey_<KEYID>.p8` 을 그 폴더에 두면 **경로와 Key ID 는 저절로 채워진다** —
애플이 파일 이름에 Key ID 를 넣어 주기 때문이다. 사람이 적는 것은 Team ID
하나뿐이고, 그것이 `/setup` 이다.

환경변수(`AM_P8` · `AM_KEY_ID` · `AM_TEAM_ID` · `OPENAI_API_KEY`)는 **있으면
언제나 이긴다.** 개발과 CI 는 그걸로 덮어쓴다.

## 첫 실행 — 로그인은 없다

Music.app 이 이미 사용자 Apple ID 로 로그인되어 있으므로 **별도 로그인이 없다.**
대신 관문이 둘이다.

| 관문 | 화면 | 해결 |
|---|---|---|
| **macOS 자동화 권한** (E1) | `PERMISSION` 배지 | `ctrl+g` 로 시스템 설정 열기 |
| **Music.app 미실행** (E2) | `MUSIC APP` 배지 | `open -a Music` |

둘 다 통과하면 그 줄은 다시 보이지 않는다.

## 실행

```
go run .                  실제 TUI
go run ./cmd/render 96    헤드리스 렌더 (TTY 없이 화면 확인)
go run ./cmd/queue "1시간 코딩용 큐"   의도 층만 확인
go run ./cmd/flow  "30분 조용한 걸로"  프롬프트→큐 전체 흐름 확인
go test ./...             폭 계산 · 필수 요소 검증
```

## 배포

```
scripts/release.sh        빌드 · 서명 · 공증 · 검역 검증  → dist/amcli.zip
scripts/build.sh          빌드만                        → dist/amcli
scripts/build.sh --dev    토큰 없이. 각자 자기 설정으로 돈다
```

**`release.sh` 가 네 단계를 한 번에 한다.** 손으로 이으면 다음에 배포할 때
순서를 다시 기억해야 하고, 하나를 빠뜨려도 **받는 사람 기계에서만 티가 난다.**

마지막 단계가 요점이다 — 압축을 풀어 **검역 표시를 직접 붙이고** Gatekeeper
판정을 받아 본다. 브라우저로 받으면 그 표시가 붙는데, 그 상태에서 통과하는지가
진짜 질문이기 때문이다. 공증이 "Accepted" 라고 나와도 여기서 막히면 배포가
안 된 것이다.

준비물(인증서 · 공증 자격 증명)이 없으면 **무엇을 하면 되는지 말하고 멈춘다.**
반쯤 만들어진 배포물을 남기지 않는다 — 서명만 되고 공증이 안 된 파일은 겉으로
멀쩡해 보인다.

한 번만 해 두면 되는 것:

```
xcrun notarytool store-credentials amcli \
  --apple-id <애플 ID> --team-id <팀 ID> --password <앱 암호>
```

앱 암호는 appleid.apple.com › 로그인 및 보안 › 앱 암호 에서 만든다.

**p8 은 배포물에 넣지 않는다.** 넣으면 누구나 뽑아서 우리 명의로 API 를
쓴다. 대신 그 키로 미리 서명해 둔 **개발자 토큰**을 박는다 — 유효기간이
최대 여섯 달이고, 새더라도 만료되면 끝이다.

**AI 키는 박지 않는다.** 그건 만료가 없어서 새면 그대로 우리 돈이 나간다.
받는 사람이 `/ai <key>` 로 자기 키를 넣거나, 안 넣고 검색·재생만 쓴다.

받는 사람이 해야 하는 것은 둘뿐이다.

| | |
|---|---|
| Music.app 자동화 권한 | 앱이 화면으로 안내한다 (`ctrl+g`) |
| `/ai <key>` | 건너뛰면 AI 만 꺼진다 |

**서명하지 않으면 브라우저로 받은 사람이 막힌다.** `curl` 이나 Homebrew 로
받으면 검역 표시가 안 붙어서 서명 없이도 돌지만, 어느 쪽으로 받을지는
우리가 못 정한다.

자동화 권한은 서명과 무관하다. 터미널에서 실행하면 애플 이벤트를 요청하는
주체가 **터미널**이라(화면도 "Allow Terminal to control Music" 이라고 적는다)
권한은 터미널에 붙지 우리 바이너리에 안 붙는다.

**단일 실행파일은 도장(stapler)을 못 박는다.** 그래서 zip 으로 배포하고,
받는 쪽이 애플 서버에 온라인으로 확인한다.

## 조작

**입력창은 늘 활성이다.** 포커스 개념이 없으므로 언제든 바로 칠 수 있다.

### 입력창은 하나지만 하는 일이 둘이다

무엇을 하는 중인지 **커서 바로 앞의 글자와 입력창 테두리 색이 말해준다.**

| 모드 | 커서 앞 | 목록 | Enter |
|---|---|---|---|
| **Ask AI** (기본) | `Ask AI` — 브랜드 색 | **건드리지 않는다** | 요청으로 보낸다 |
| **Search** (`shift+tab` · `ctrl+f`) | `Search` — 회색 | **즉시 걸러진다** | 고른 곡을 튼다 |
| 명령 (`/` 로 시작) | `Ask AI` | 건드리지 않는다 | 로컬 실행 |

기호가 아니라 **글자**를 쓴다. 기호는 배워야 알고 한 번 배워도 둘을
헷갈린다. 두 프롬프트의 폭을 같게 맞춰서 모드를 바꿔도 글자가 시작하는
칸이 안 흔들린다.

검색은 두 구역을 보여준다 — 위는 이미 내 것, 아래는 아직 내 것이 아닌 것.
위 구역에는 상한이 있어서 **Apple Music 구역이 화면 밖으로 밀리지 않는다.**

| 키 | 동작 |
|---|---|
| 아무 글자 | 입력창에 들어간다 |
| `shift+tab` | 모드 바꾸기 — `Ask AI` ⇄ `Search` |
| `ctrl+f` | 곧장 검색으로 |
| `ctrl+j` | 대화 띠 접기 · 펴기 |
| `/` | 명령 팔레트 — 갈 곳과 할 것 |
| `tab` | 다음 섹션. 먼 곳은 `/artists` 처럼 곧장 간다 |
| `shift+←` `shift+↓` `shift+→` | 이전 · 재생/일시정지 · 다음 |
| `ctrl+g` | (권한 막혔을 때) 시스템 설정 열기 |
| `↑` `↓` (`ctrl+p` `ctrl+n`) | 목록 이동 |
| `enter` | 요청 보내기 · 고른 곡 재생 |
| `esc` | 한 단계씩 물러난다 |
| `ctrl+c` | 종료 |

`j` `k` `h` `l` 같은 알파벳 단축키는 두지 않는다.
입력창이 늘 활성인 구조에서는 자연어와 반드시 충돌한다.

## 인식 — `/shazam`

마이크로 몇 초 듣고 무슨 곡인지 말한다. 알아맞힌 곡이 **이미 라이브러리에
있는지**를 함께 말하는 것이 이 서비스가 Shazam 보다 더 하는 일이다.

ShazamKit 은 Go 에서 부를 수 없어 옆에 Swift 헬퍼를 세운다. 먼저 만들어야 한다.

```
make -C ../helper
```

카탈로그 대조에는 Apple 의 ShazamKit 엔타이틀먼트가 필요하고, 그것만은
개발자 포털에서 한 번 받아와야 한다 — `helper/README.md`. 없으면 `/shazam`
이 왜 안 되는지 로그에 적고 나머지 기능은 그대로 돈다.

## 타입은 손으로 쓰지 않는다

`internal/api/types.gen.go` 는 API 명세에서 생성된다.

```
go run github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@latest \
  -config oapi-codegen.yaml ../api/openapi.yml
```

명세에 없는 필드를 화면이 그리려 하면 컴파일이 안 된다.
